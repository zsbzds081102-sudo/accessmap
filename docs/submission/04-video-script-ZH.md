# 明天录视频脚本（中文口播 + 英文界面操作）
目标时长：约 2.5–4 分钟（Devpost 要求 2–6 分钟）
演示地址：https://zsbzds081102-sudo.github.io/accessmap/
录前：强制刷新（Cmd+Shift+R）；语言保持 EN。

## 镜头 0｜片头（10–15 秒）
口播：「大家好，我是七台河市第一中学的高三学生。我们学校正门只有台阶、没有坡道，坐轮椅的同学进不了校门。我做了 AccessMap——校园无障碍地图和障碍上报。」
画面：打开网站首页，地图框住校园。

## 镜头 1｜问题真实（20 秒）
口播：「正门是全校进出的必经之路。主教学楼有电梯，课还能上；但正门过不去，后面都白搭。」
画面：点正门钉点 / 看侧栏今天能不能进。

## 镜头 2｜20 秒演示路径（45–60 秒）★必录稳
操作（不要切中文）：点 Play 20 seconds，按 Next 走完三拍。
口播：「评委二十秒路径：发现障碍、看到还能上课的地方、再看学校该先修哪里。」

## 镜头 3｜学校可拿走的清单（30–40 秒）★加分
操作：School 模式 → 本周修缮优先级 → 复制或下载 CSV。
口播：「学校视角会排出修缮顺序，还可以一键复制或导出，直接转给后勤——数据只在浏览器里，没有账号。」

## 镜头 4｜同学上报（25–35 秒）
简短走上报或筛选。口播：「同学发现新障碍可以上报；学生上报会优先排进修缮清单。」

## 镜头 5｜无障碍（20–30 秒，建议）
Tab 走控件或开关 Voice。口播：「键盘和读屏也能用；语音用系统自然音色。」

## 镜头 6｜结尾（15 秒）
口播：「AccessMap 是我第一次参加黑客松的作品。希望它能帮我们学校先把正门坡道修起来。谢谢。」
字幕可叠：https://zsbzds081102-sudo.github.io/accessmap/
